# Power BI Report

This folder contains the interactive Power BI deliverable for the Retail Sales and Returns Analytics portfolio project.

## Report file

Expected file:

`Retail_Sales_Returns_Analytics.pbix`

The report contains two main pages:

- **Executive Overview** — net sales after refunds, refund KPIs, category performance and monthly trend analysis.
- **Returns Analysis** — refund drivers, return rate by category, return reason analysis and Top 10 products by refund amount.

For the report design, data model, DAX examples and analytical decisions, see [Power BI dashboard documentation](../docs/power_bi_dashboard.md).

## How to open

Download the PBIX and open it with Microsoft Power BI Desktop.

The Power BI layer complements the Excel and SQL components already included in this repository and uses the same cleaned retail data and business definitions.
